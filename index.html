01
Role-based prompting

The Placement Preparation Assistant

Scenario — A final-year AIML student has a campus placement interview tomorrow. Asking “Tell me about Java” produces a lengthy response with advanced topics the student cannot revise in one day.

Your task

  1. Assign the AI the role of an experienced Java interviewer.
  2. Request five basic Java interview questions with short answers.
  3. Specify that answers must suit a final-year engineering student.
  4. Compare the result with the original vague request.
Learning outcome: See how role, audience, and constraints make responses more relevant.
02
Closed-ended prompting

The Last-Minute Exam Revision Assistant

Scenario — A student has 30 minutes to revise Machine Learning. They need a quick revision sheet, not a lengthy explanation.

Your task

  1. Ask the AI to explain supervised, unsupervised, and reinforcement learning.
  2. Require a table with Learning Type, Simple Explanation, and Real-Time Example.
  3. Limit each explanation to two sentences.
  4. Check the format and length of the response.
Learning outcome: Control the scope, format, and length of an AI response.
03
Context-rich prompting

The Python Error Assistant

Scenario — A beginner encounters ZeroDivisionError: division by zero and receives a complicated explanation from an AI tool.

Your task

  1. Ask for a beginner-friendly explanation of the error.
  2. Request a small Python example that produces it.
  3. Ask for corrected code and why the correction works.
  4. Run or inspect the code to verify the answer.
Learning outcome: Use context, skill level, and expected output to improve technical assistance.
04
Open-ended prompting

The Smart Campus Innovation Challenge

Scenario — Your department wants students to build a basic AI project that solves a real campus problem, but your team has no idea yet.

Your task

  1. Ask for five simple AI project ideas for a college campus.
  2. Request the problem, solution, tools, and expected benefit for each.
  3. Restrict ideas to a basic student implementation level.
  4. Refine the prompt if ideas are too complex or repetitive.
Learning outcome: Use open-ended prompts for brainstorming, creativity, and planning.
05
Probing & bias mitigation

The Fair Resume Screening Assistant

Scenario — A company uses AI to shortlist software developer candidates. You suspect it may prefer candidates based on gender or other irrelevant personal characteristics.

Your task

  1. Probe whether the AI evaluates job-relevant skills and qualifications.
  2. Compare hypothetical candidates with equivalent technical skills but different irrelevant characteristics.
  3. Identify unfair differences, if any.
  4. Rewrite the prompt to emphasize consistent, skills-based evaluation.
Learning outcome: Identify potential bias and encourage fairer, job-relevant assessment.
06
Adversarial prompting

The Unreliable College Helpdesk Chatbot

Scenario — A college chatbot answers questions about admissions, examinations, and fees, but sometimes invents facts when it does not know the answer.

Your task

  1. Restrict answers to supplied college information.
  2. Ask a question whose answer is missing from that information.
  3. Test with a misleading or contradictory question.
  4. Improve the prompt so unknown information is clearly identified.
Learning outcome: Use stress tests to reveal weaknesses and improve reliability.
07
Prompt optimization

The Project Presentation Assistant

Scenario — You need five slides on “Applications of AI in Healthcare,” but the first AI response is a lengthy essay rather than presentation-ready content.

Your task

  1. Create an initial prompt for presentation content.
  2. Refine it to require exactly five slides, a title, three bullets, and one practical example per slide.
  3. Compare the two outputs.
  4. Choose the better prompt and explain why.
Learning outcome: Improve prompts iteratively by comparing outputs against requirements.
08
Performance evaluation

The AI Answer Quality Evaluator

Scenario — Two prompts explain cloud computing to first-year students. One answer is simple and example-driven; the other is technically correct but confusing.

Your task

  1. Create two different prompts to explain cloud computing to beginners.
  2. Generate one answer from each prompt.
  3. Score accuracy, clarity, relevance, and usefulness from 1 to 5.
  4. Choose the stronger prompt based on the scores.
Learning outcome: Evaluate prompt quality systematically instead of judging by how impressive an answer sounds.
09
Constraints & refinement

The Personalized Study Planner

Scenario — An AIML student has five subjects and only three hours per day to study. A generic timetable exceeds the daily limit and leaves some subjects uncovered.

Your task

  1. Specify five subjects and examination dates of your choice.
  2. Ask for a day-wise timetable.
  3. Require a maximum of three study hours daily and coverage of all subjects.
  4. Check the schedule and refine the prompt if it breaks the constraints.
Learning outcome: Express constraints precisely and verify that the generated plan follows them.
10
Ethical prompting

The Responsible AI Project Assistant

Scenario — A student wants to predict academic performance and plans to upload real student names, phone numbers, marks, and attendance to an online AI tool.

Your task

  1. Ask for an approach using fictional or anonymized data.
  2. Request likely privacy risks and possible prediction bias.
  3. Ask for three practical steps to protect information and promote fairness.
  4. Refine the prompt to avoid exposing personally identifiable information.
Learning outcome: Encourage privacy-aware, responsible, and fair AI use.

What to submit

Use these six evidence items in your lab record or answer sheet.

  1. Problem understanding
    What problem does the scenario present?
  2. Initial prompt
    The first prompt submitted to the AI.
  3. AI output
    The response received from the tool.
  4. Improved prompt
    Your refined version after identifying shortcomings.
  5. Final output & verification
    The improved response and how you checked it.
  6. Learning
    Why did the improved prompt work better?

The goal is not to write the longest prompt. The goal is to communicate the task, context, constraints, and expectations clearly—and verify the result. A good AI user does not simply accept an answer; they know how to improve it.
